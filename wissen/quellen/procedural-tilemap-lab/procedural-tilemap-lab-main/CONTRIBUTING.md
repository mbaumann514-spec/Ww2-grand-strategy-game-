# Contributing

Issues and focused pull requests are welcome.

- Keep changes scoped and preserve seeded reproducibility unless a breaking
  change is intentional and documented.
- Run `npm test` for ordinary changes and `npm run check` for release-level or
  generator-wide changes.
- Do not add images, fonts, or other media unless their origin and public reuse
  terms are documented.
- Keep user-facing setup and behavior in the root README files. Do not add
  internal plans or implementation notes to the repository documentation.

For substantial API, data-contract, or generation changes, open an issue first
so the intended compatibility boundary can be agreed before implementation.
